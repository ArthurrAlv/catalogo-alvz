# Arthur Alves — portfólio ALVZ

Landing page estática em HTML, CSS e JavaScript, sem dependências de build.

## Executar

Execute `python -m http.server 8080 --bind 127.0.0.1` e abra http://127.0.0.1:8080/.

- `index.html`: versão atual, também disponível em `experimental.html`.
- `previous.html`: versão anterior à abertura fotográfica.
- `experimental-modal-backup.html`: comparação histórica com modais.
- `demos/gamecamp/`: apresentação original isolada, sem autenticação ou banco.

## Identidade e conteúdo

Georgia no título da abertura; Manrope nos textos; assinatura SVG fornecida por Arthur. Cores centralizadas em tokens CSS. Motion respeita a preferência por movimento reduzido. Galerias e revelações ficam na própria landing page.

Esboços fornecidos são apresentados como estudos visuais, sem atribuir um processo histórico não confirmado. O ícone DJ Nogs é um recorte demonstrativo e precisa de validação. A versão monocromática é um estudo derivado.
